# javascript-calculator-precourse

기능 목록

1. 문자열 입력 받기
2. 문자열 파싱
    1. `//<문자>\n` 형태가 있으면 `<문자>`를 커스텀 구분자로 지정
    2. 그렇지 않으면 `,`나 `:`를 구분자로 지정
    3. 구분자를 기준으로 문자열 분할
    4. 각 원소들이 양의 정수인지 검사
3. 총합 계산
4. 결과 출력

예외 처리

1. `//<문자>\n` 패턴이 두 개 이상 입력된 경우
2. 음수 또는 0이 있는 경우
3. 구분자에 숫자가 포함된 경우
4. ~~입력이 없는 경우 -> 0으로 처리~~
5. ~~숫자 입력이 없는 경우 -> 0으로 처리~~
6. ~~구분자가 연속으로 나오는 경우 -> ux를 위해 0으로 처리~~

테스트 사항

1. 커스텀 구분자를 정상적으로 추출하는가
2. 음수나 0에 대한 예외처리가 잘 되어 있는가
