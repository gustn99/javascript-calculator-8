# javascript-calculator-precourse

## 1. 사용자 입력

- "덧셈할 문자열을 입력해 주세요."

## 2. 구분자 파싱

- 숫자로 시작하는 문자열이면 `,` 또는 `:`를 구분자로 설정
- `//<문자>\n`로 시작하는 문자열이면 `<문자>`를 구분자로 설정
- `//<문자>\n` 패턴이 여러 개 반복 -> **[ERROR] 구분자는 한 번만 선언할 수 있습니다.**
- `<문자>`에 숫자가 들어온 경우 -> **[ERROR] 숫자는 구분자가 될 수 없습니다.**
- `<문자>`가 비어 있는 경우 -> **[ERROR] 구분자는 하나 이상의 문자여야 합니다.**

## 3. 숫자 파싱

- 구분자를 기준으로 파싱
- 각 부분을 number 형변환
- 구분자 외 다른 문자열 포함 -> **[ERROR] 지정한 구분자 외의 문자가 포함되어 있습니다..**
- 구분자 사이에 숫자가 없음 -> **[ERROR] 잘못된 수식입니다.**
- 입력의 양끝이 구분자 -> **[ERROR] 잘못된 수식입니다.**
- 음수나 0이 있으면 -> **[ERROR] 양수만 입력 가능합니다.**

## 5. 출력

- 입력이 빈 문자열 -> 0 출력
